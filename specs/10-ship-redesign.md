# SPEC 10 — 機体デザイン刷新（一体成形のSF迎撃機）

状態: **Verified（2026-09-23 phaseS1 10/10・run-all 20スイート324テスト ALL GREEN）** ／ 依頼: 「つぎはぎ感を解消し、リアリティのあるSFとしてかっこいい機体に」 ／ 前提: SPEC-09 Verified ／ 外部素材: 不要

## 1. 課題（現状の分析）

現行の機体は **四角錐(機首) + 薄い箱(主翼) + 箱(尾翼) + 円柱(ノズル)** を重ねただけの構成。

| 問題 | 原因 |
|---|---|
| つぎはぎに見える | 部品どうしが「刺さっているだけ」で、面が繋がっていない（主翼が胴を貫通、尾翼が板のまま浮く） |
| 形に説得力がない | 機首が4面の角錐で断面が菱形のまま後ろへ続かない。胴体がほぼ存在しない |
| 素材が単調 | 全部品が同じ外板1色。ガラス（キャノピー）・吸気口・暗色部がなく、スケール感が出ない |
| 発光が中心にある | 胴の中央後方の発光球がエンジン位置（左右）と一致しない |

## 2. デザイン方針「ステルス迎撃機」

- **一体成形の胴体**: 機首先端から尾部まで、断面が滑らかに変化する**ロフト形状**（8角の「チャイン」断面。上面は丸く、側面に稜線）
- **後退翼（デルタ）**: 胴体側面から生える後退角つきの主翼。翼端は切り落とし、面取り（ベベル）で厚みの縁が光を拾う
- **双垂直尾翼**: 外側へ傾けた2枚（中央の1枚板を廃止）
- **エンジンナセル**: 左右のエンジンを胴体と主翼の付け根に一体化。後端に暗色のノズルと発光
- **キャノピー**: 胴体上面に溶け込む涙滴形のガラス（暗色・高反射、内側にわずかな計器光）
- **2トーン**: 明るいチタン外板 + グラファイトの暗色部（吸気口・ノズル・尾翼先端・機銃）
- **装備**: 胴体下の左右に機銃2門（曳光弾の発射位置をここに合わせる）
- 発光は **ノズル・翼端灯・キャノピー内・細い航法灯** に限定（外板は発光しない＝SPEC-09 の方針を継承）

## 3. 要件

| ID | 要件 |
|---|---|
| S-01 | 胴体はロフト形状の独自ジオメトリ（`ConeGeometry` / `BoxGeometry` を外板に使わない） |
| S-02 | 部品がつながっている: 外板・暗色部・キャノピーの各メッシュは、少なくとも1つの他のメッシュと体積が重なる（浮いた部品がない） |
| S-03 | 外形は現行とほぼ同じ大きさ（全幅 7.5±0.3・全長 5.2〜6.4・高さ ≤2.6）。ゲームの難度とサイトの構図を変えない |
| S-04 | 当たり形状を新形状に合わせて再定義。**球とカプセル（線分を太らせた形）計 ≤12 個**で外形に沿わせ、外板頂点の **95% 以上**を包含、翼端・機首先端・尾翼上端を包含（後退翼と細長い胴体は球4個では「空気」に当たる範囲が大きく、難度が上がるため） |
| S-05 | 材質3系統以上: 外板（金属度 ≥.8）/ 暗色部 / ガラス（粗さ ≤.12・金属度 ≥.8）。外板の emissive は通常 0 |
| S-06 | 互換: `parts` の `exhaust`(2)・`tips`(2)・`nozzles`・`nozzleGlow`・`hull`・`plumeMat` を維持し、`canopy` を追加 |
| S-07 | 機関砲の曳光弾は機銃の砲口から出る |
| S-08 | 性能: 機体のメッシュ数 ≤16、三角形数 ≤6,000 |
| S-09 | 見え方: 追跡視点で機体シルエットの飽和 ≤15%（F6-T05 と同条件）、機体の画面占有率は現行の 0.8〜1.5 倍 |
| S-10 | 既存テスト（19スイート）全グリーン。当たり判定の端点テスト F1-T03 は新形状の端点に改訂 |

## 4. 技術設計

- `loft(sections)`: 断面リスト `{z, w, top, bot, chine}` から8角断面を作り、隣接断面を四角形で接続。先端は1点に収束、後端は面で閉じる
- 主翼・尾翼: `THREE.Shape`（平面形）→ `ExtrudeGeometry`（厚み + ベベル）→ 回転して配置。左右は点列を鏡映して作る
- 外板のUVは既存の `boxUV`（機体座標で投影するため、部品をまたいでパネル模様が連続する）
- すべてのジオメトリを**機体座標で生成**し、メッシュ自体は原点に置く（部品間のズレが原理的に出ない）
- 当たり形状: 胴体前後・左右ナセル・主翼の前縁/後縁はカプセル、翼端・尾翼は球。`clearance` はカプセル軸上で岩に最も近い点を球の中心として扱う（既存の掃引判定・ニアミス判定はそのまま使える）
- 公平性検証の機体半長 `SHIP_HL` を 2.6 → 3.2（全長 6.2 に合わせる）

| 既存 | 改訂 | 理由 |

| F1-T03 翼端(±3.75,-.4,1.2)・機首(0,0,-2.6) の固定座標 | 新形状の端点（x最大/最小・z最小・y最大）を幾何から求めて検証 | 形状の変更 |

## 7. 実装時の判断

- **当たり形状**: 球4個では新形状の被覆が 33% しかなく、覆うように大きくすると当たり体積が旧比 1.45 倍（難度上昇）になった。
  球とカプセル計12個にし、半径を「被覆 ≥95%」と「体積 ≤1.2 倍」の両立で数値的に決定（**被覆 97.7%・体積 1.14 倍**）。S-T10 を追加
- **機銃**は当初の翼下(x=±1.0)だと当たり形状の外に出るため、機首下のチン・ガン(x=±0.45)に変更（見た目も一体感が出た）
- **外板の模様**: 近距離でリベットが目立ち旧式機に見えたため、パネルを大きく・リベットを少なく細く・継ぎ目を浅くし、パネルごとの色むら（アルベド）を追加
- **明るさ**: 新機体は中央の発光球がない分、追跡視点の画面平均が下がった（F2 の下限 0.5 倍を僅かに下回る）。
  ゲームはノズル光を強め（×1.8）、サイトは近接で正対する章があるため ×1.4 に抑える（`buildShip({glow})`）。
  サイトの機体照明は面取りの縁が白飛びしないよう 110 → 95
- **環境マップの恒星**: 鏡面の光沢を主光と二重に拾ってブルームが大きくなるため、輝点を 60 → 15 に抑えた
- 公平性検証の機体半長 `SHIP_HL` を 3.2 に更新（全長 6.19）
