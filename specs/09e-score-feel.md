# SPEC 09e — Phase F5: スコア体系（ニアミス・コンボ・撃破）と手応え

状態: **Draft** ／ 親: [SPEC-09](09-realism-gameplay-policy.md) G3 + G4 ／ 前提: F1（clearance）・F3（セクター）Verified ／ 外部素材: 不要（効果音は Web Audio 合成）

## 1. 目的

「上手さが画面と点数に出る」。避け方・攻め方がその場で気持ちよく反応し、点数として残るようにする。

### 現状
- スコア = `floor(dist*10 + cores*500)`（生存時間でほぼ決まる）
- 手応え: 被弾時の画面揺れ・赤フラッシュ・減速・計器グリッチ、速度連動の FOV（72→84）と流線

## 3. 技術設計

### 3.1 ニアミス判定（F5-01）

```js
// loop 内の岩ループ（F1 の clearance を再利用）
const c = clearance(m, shipSpheres, sd);
if(c < 0){ hit(now, m); ... }
else if(!inv && !m.userData.nm && c <= NEAR && crossedShipZ(m, sd)){
  m.userData.nm = true;             // 岩ごとに1回（プールへ戻す時にリセット）
  addScore('near', 150);
  SoundEngine.whoosh(Math.sign(m.position.x - ship.position.x));
  fovKick = 4;
}
```

### 3.2 コンボ・加点（F5-02〜05）

```js
const COMBO_TIERS = [[35, 4], [20, 3], [10, 2], [5, 1.5], [0, 1]];
function addScore(kind, base){
  st.combo++; st.comboT = 4;
  const mult = COMBO_TIERS.find(([n])=>st.combo >= n)[1];
  if(mult > st.mult){ SoundEngine.combo(tierIndex(mult)); }
  st.mult = mult;
  st.score += Math.round(base*mult);
  st.tally[kind].n++; st.tally[kind].pts += Math.round(base*mult);
  pop(kind, Math.round(base*mult));
}
// 毎フレーム: st.comboT -= dt; if(st.comboT <= 0){ st.combo = 0; st.mult = 1; }
// hit(): st.combo = 0; st.mult = 1;
```

- コア回収（`pickupCore`）は `addScore('core', 0)`（点は残コアとして最後に数えるため 0。コンボだけ伸びる）

### 3.3 ヒットストップ（F5-10）

```js
if(now < hitStopUntil){ simDt = 0; } else { simDt = dt; }
// 岩の移動・速度上昇・距離加算・生成は simDt、揺れ・FX の減衰・描画は dt
```

### 3.4 音（F5-12/13）

- `whoosh(pan)`: バンドパスをかけたノイズ（中心周波数 1.2k→400Hz へ 0.25 秒で下降）+ StereoPanner
- `combo(tier)`: 三角波 2 音、基音 = 440×2^(tier×2/12)
- `intensity(k)`: `engineStart` で脈動レイヤー（矩形波 55Hz × LFO 4〜8Hz、ローパス 300〜1800Hz）を起動し、k でゲインとカットオフを補間。`engineStop` で停止
- すべて既存の `voice()` / `env()` / ミュート制御に従う。`_test().lastSfx` に種別を記録

| リスク | 対策 |

| ニアミス狙いで被弾が増え、初心者が不利 | 距離点は倍率なしで残るため、安全に飛んでも従来並みの点は取れる |
