# SPEC 14 — パイロットの手（グローブ）

状態: **Withdrawn（2026-09-26 撤去: 「コードだけで手の表現は難しいため、手はなしで良い」— 本番から削除。記録として残す）** ／ 依頼: 「パイロットの手（グローブ）も追加してください」 ／ 前提: [SPEC-13](13-cockpit-holo.md) Verified ／ 外部素材: 不要（プロシージャル生成） ／ テスト: `tests/phaseG1.js`

## 1. 方針

- **右手が中央の操縦桿を握る**。手の甲は右後方（パイロット側）を向き、指はグリップの前へ回り込み、親指は頭頂のハットスイッチの横に置く。人差し指はトリガーに掛かる
- 左手は出さない（SPEC-13 でスロットルを撤去したため、左手の置き場が画面内にない。計器を隠さない）
- 手は操縦桿の子にして**操縦桿と一緒に傾く**。発射時は**人差し指がトリガーを引く**
- 造形は SF のフライトグローブ: 合成皮革の手袋＋手の甲と指の付け根の装甲板＋手首の袖口に状態色の細い発光線＋飛行服の袖（右下へ画面外に抜ける）
- 質感は SPEC-09/13 と同じ水準（環境反射あり・材質を分ける）。レティクル（CON-05）・ゲームのルールは変えない

## 2. 形状（操縦桿のグリップ座標。グリップ軸 = y、半径 ≈ .036、前 = -z、SPEC-13 の本体倍率 1.3 がそのまま掛かる）

**手はグリップの右から握る**（手の甲がパイロット側を向き、拳はグリップの右前、手首と袖は右下へ）。
グリップの後ろから握る実際の姿勢では、手が画面の下端より下に隠れて親指しか見えなかったため（§7）。

## 7. 実装時の判断

- **握る向き**: 最初は実物どおり手をグリップの後ろ（パイロット側）に置いたが、カメラが操縦桿のすぐ上後ろにあるため手が画面の下端より下に入り、
  親指だけが棒のように見えた。**グリップの右から握る姿勢**にして、手の甲・拳・親指が画面内に収まるようにした
- **大きさ**: グリップの直径（実寸換算で約 9cm）に対して手が細く、指が細い管に見えたため、指の太さ・手の甲を約 1.6 倍に（グリップを細くすると SPEC-13 の見た目が変わるため、手の側で合わせた）
- **色**: グリップと同じ青灰色では手と区別できなかったため、グローブを暖色の合成皮革（0x3d3833）、装甲を明るいガンメタルに
- **三角形数**: 当初 5,828（上限 5,000 超）→ カプセルの分割数を下げて 3,712
- SPEC-13 の「操縦席のメッシュ ≤ 24（手を除く）」はそのまま。手は別枠で 5 メッシュ。全体の draw call は 109〜114（上限 155）
- 実測: 握り（関節点の接触）100%・芯への食い込み 0%・占有率 14.9%（上限 21.6%）・中央域 0 画素（FOV 72° / 84° / 操縦桿を最大に傾けた状態）
