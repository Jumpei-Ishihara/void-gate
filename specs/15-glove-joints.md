# SPEC 15 — パイロットの手: 継ぎ目を関節に見せる工夫（検討）

状態: **Proposal（案の選定待ち）** ／ 依頼: 「図形の組み合わせで作成しているが、つなぎめを関節のように見せる工夫を検討」 ／ 前提: [SPEC-14](14-pilot-glove.md) Verified
確認用ページ: [labs/glove-joints.html](../labs/glove-joints.html)（本番と同じ照明・環境反射・ACES で 4 種を切替。クローズアップ／操縦席視点） ／ 比較画像: `labs/glove-shots/glove-joints-sheet.jpg`

## 1. 現状の継ぎ目（SPEC-14）

| 場所 | 作り | 見え方の問題 |
|---|---|---|
| 指の関節 | 関節ごとに別のカプセルを重ねる | 太さが一定で、つなぎ目に「くびれ」も「影」もない → 曲がる場所が読めない。ソーセージ状 |
| 指の付け根 | カプセルの端が手の甲（楕円体）に刺さる | 刺さり目が硬い線になる |
| 親指 | 2 本のカプセル | 操縦席視点で一番よく見える部位なのに、棒 2 本に見える |
| 手の甲の装甲 | 平らな箱を楕円体に重ねる | 曲面に平板が「刺さって」見える |
| 手首 | 円錐台を楕円体に重ねる | 手と袖の境が不自然 |

## 2. 関節に見せる手法

| 手法 | 内容 | 効果 |
|---|---|---|
| **継ぎ目のない曲線チューブ** | 指を関節点を通る 1 本の曲線（Catmull-Rom）に沿ったチューブにする。付け根は手の甲の中から始める | 部品の重なり目そのものが消える |
| **くびれと膨らみ** | チューブの太さを関節で −13% くびらせ、その手前を +7% 膨らませる | 実際の指と同じ「関節で細く、指節で太い」輪郭 |
| **擬似 AO（頂点の明るさ）** | 関節のしわ・グリップ側の面の頂点を暗くする | 影で「折れ目」が読める。描画コストは 0 |
| **関節のゴムの帯** | 関節の位置に細い暗色の輪 | 遠目でも関節の位置がわかる（フライトグローブの伸縮部の文法） |
| **指節ごとの装甲板** | 指節の外側に湾曲した板。関節で板を切り、隙間から関節（ゴム）を見せる | 「板の切れ目＝関節」。メカ・パワードスーツの文法 |
| **曲面の殻** | 手の甲の装甲を楕円体の面に沿う殻にする | 平板の刺さりをなくす |
| **蛇腹（ベローズ）** | 手首を波打つ回転体にし、谷を暗くする | 手と袖の境を「曲がる部品」として見せる |

## 3. 3 案

| | 案1 ORGANIC | 案2 ARMORED | 案3 HYBRID（推奨） |
|---|---|---|---|
| 指 | 継ぎ目のない革のチューブ＋くびれ＋しわの影 | ゴムの芯＋指節ごとの装甲板＋隙間の関節球 | 案1の革の指＋関節のゴムの帯＋付け根の指節だけ装甲 |
| 親指 | 同上 | 装甲板 2 枚 | 付け根に装甲＋関節の帯 |
| 手の甲 | 革（縁ほど明るく） | 重なり合う 3 枚の板 | 曲面の殻の装甲 |
| 手首 | 革のしわの溝 2 本 | ゴムの蛇腹 | ゴムの蛇腹 |
| 印象 | 最も自然な革手袋。SF 感は控えめ | 最もメカ的。遠目には細かくうるさい | 形は有機的、要所に SF の装甲。関節の位置が読める |
| 操縦席視点での差 | 小（親指のくびれ程度） | 大（金属の板が光る） | 中〜大（親指の帯と装甲、手の甲の殻） |
| 三角形（試作・未最適化） | 11,328 | 14,644 | 14,968 |

- 試作は形を比べるため細かく分割している。本番では分割を減らして **7,000 以下** に収める見込み（チューブ 56×14 → 28×10、帯・蛇腹の分割も半分）。メッシュ数は 5 のまま（draw call は現状と同じ）

## 4. 推奨

**案3 HYBRID**。
- 操縦席視点で実際に見えるのは「親指・手の甲・手首」。案3はこの 3 か所すべてに関節の手がかり（帯・曲面の殻・蛇腹）がある
- 指全体は案1の継ぎ目のない形なので、クローズアップでも重なり目が見えない
- 装甲を要所に絞るため、案2のような細かさ・光りすぎがない

## 5. 実装する場合の要点（SDD+TDD で進める）

- `buildGlove` を差し替え（姿勢・寸法・握り・人差し指のトリガー動作は SPEC-14 のまま）。人差し指は曲線チューブを支点ごと回す
- 頂点色を保つ結合関数を追加（現行の `Assets.mergeGeo` は色を捨てるため）
- テストの追加案: 指が 1 本の連続した形状であること（指ごとの部品数）・関節のくびれ比・擬似 AO の暗さ・帯の位置が関節点に一致・三角形 ≤ 7,000。既存の G-T01〜T08 はすべて維持

## 6. 確認したい点

- 案の選択（推奨: 案3）
- 三角形の上限を 5,000 → 7,000 に上げてよいか（draw call は増えない）
